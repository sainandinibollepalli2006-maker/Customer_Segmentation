# Customer Segmentation & Sales Analytics Dashboard

## Project Overview

This project analyzes customer purchasing behavior using RFM analysis and K-Means clustering.

The final customer segments are visualized using a Power BI dashboard.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab
- Power BI

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. RFM Analysis
4. Data Standardization
5. K-Means Clustering
6. Customer Segmentation
7. Power BI Dashboard

## Customer Segments

- Regular Customers
- Inactive Customers
- Loyal High-Value Customers
- VIP Customers

## Dashboard Features

- Total Sales
- Total Customers
- Total Orders
- Total Products
- Customer Segments
- Monthly Sales Trend
- Top 10 Products by Sales
- Sales by Country

## Files

- `customer_segmentation_sales.csv` — Processed dataset
- `Customer_Segmentation_Sales_Dashboard.pbix` — Power BI dashboard
- `README.md` — Project documentation

## Objective

The objective of this project is to identify customer groups based on purchasing behavior and generate useful sales insights through data analysis and visualization.
